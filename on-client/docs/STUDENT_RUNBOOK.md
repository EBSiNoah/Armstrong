# 학생 실행·구성 안내서

이 문서는 다른 사람이 이 프로젝트의 실제 폴더 위치와 실행 순서를 확인할 수 있도록 작성했습니다. 기존 문서는 수정하지 않았습니다. 이 문서 작성 과정에서는 프로젝트 파일과 문서만 확인했으며, PowerShell·브라우저로 앱을 실행하거나 외부 서비스에 연결하지 않았습니다. 따라서 아래의 실행 결과는 **실행 방법과 코드에 적힌 신호**이지, 이번 작업에서 실행 성공을 확인했다는 뜻은 아닙니다.

## 1. 필요한 프로그램과 확인한 버전

| 항목 | 프로젝트에서 확인한 내용 | 준비 방법·한계 |
|---|---|---|
| Windows PowerShell | 실행 도구가 `.ps1` PowerShell 스크립트입니다. | Windows PC에서 앱 폴더를 작업 위치로 열어 사용합니다. 이번 작업에서 PowerShell 버전은 확인하지 않았습니다. |
| Node.js | `package.json`의 `engines.node`는 **24.19.0**입니다. 실행 도구는 Node.js **22~24**를 허용하고 24.19.0을 권장합니다. | 수업 기준 버전은 24.19.0입니다. 이것은 저장소에서 확인한 요구·권장 버전이며, 학생 PC에 설치된 버전을 확인한 결과가 아닙니다. 이번 작업에서 실제 런타임 버전은 확인하지 않았습니다. |
| npm | `package.json`에 `start`, `demo`, `check` 스크립트가 있습니다. | `npm` 명령을 쓸 때 필요합니다. 실행 스크립트 자체는 Node.js를 직접 실행하므로 npm 없이도 실행할 수 있습니다. |
| 브라우저 | 로컬 웹 화면을 여는 데 필요합니다. | `http://127.0.0.1:5189/`를 엽니다. 이번 작업에서는 브라우저 호환성이나 화면 표시를 시험하지 않았습니다. |
| 추가 npm 패키지 | `package.json`에는 `dependencies`가 선언되어 있지 않고 README는 외부 npm 의존성이 없다고 설명합니다. | 앱 시작을 위해 `npm install`을 하라는 명령은 이 안내서에 추가하지 않았습니다. |

## 2. 실제 폴더 구조와 PowerShell을 여는 위치

현재 저장소 트리에서 앱 폴더는 `Armstrong-main/on-client/`입니다. 배포된 시작 틀에서는 같은 앱 폴더의 이름이 `on-client`입니다. 아래 실행 명령은 반드시 `tools`, `src`, `package.json`이 함께 있는 **앱 폴더(on-client)**를 기준으로 합니다. 저장소 상위 폴더나 `docs` 폴더에서 실행하지 않습니다.

```text
Armstrong-main/on-client/
├── package.json                 # start, demo, check 및 Node 버전 계약
├── README.md
├── docs/                        # 학생 안내, 문제 해결, 연결 계약
├── public/                      # 브라우저 화면·스크립트·스타일·이미지
├── src/
│   ├── server.mjs               # 로컬 HTTP 서버와 API
│   ├── engine.mjs               # 연결 없음·예제·어댑터 선택
│   ├── engine/                  # SDP 설정·엔진 경계
│   ├── ai/                      # 서버 측 AI·연결 기능
│   └── vulnerabilities/         # 프로젝트 패키지·OSV 조회
├── student/
│   ├── extension.mjs            # 학생 표시 함수가 들어가는 모듈
│   └── engine-adapter.mjs       # 호스트 기능을 학생 엔진 인터페이스로 전달
├── tools/
│   └── start-alekov.ps1         # Node·폴더·포트 확인 후 서버 실행
└── vendor/                      # 저장소에 포함된 CLCO HTTP 클라이언트
```

**PowerShell 위치 열기:** 파일 탐색기에서 실제 `on-client` 폴더를 연 뒤 주소 표시줄에 `powershell`을 입력하고 Enter를 누릅니다. 열린 창의 현재 위치가 `on-client`여야 합니다. 시작 스크립트는 링크/바로가기 경로를 거절합니다.

## 3. 처음 실행하기

앱 폴더의 PowerShell에서 다음 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

`-ExecutionPolicy Bypass`는 이 명령으로 시작하는 PowerShell에만 적용됩니다. 실행 도구 설명에 따르면 PC의 실행 정책을 전역 변경하거나 프로그램을 설치하지 않습니다. 도구는 `src/server.mjs`를 실행하고 `127.0.0.1`의 포트 5189에 응답하는지 확인한 다음 주소를 출력합니다.

### 브라우저 주소와 정상 시작 신호

기본 주소는 다음과 같습니다.

- 브라우저: `http://127.0.0.1:5189/`
- 대체 포트 5190 사용 시: `http://127.0.0.1:5190/`

실행 도구가 HTTP 200 응답을 확인하면 PowerShell에 다음과 같은 문구를 출력합니다.

```text
케셰브가 켜졌습니다. 브라우저에서 http://127.0.0.1:5189/ 을 여세요.
서버가 응답한 것만 확인했습니다. AI 연결 상태는 화면에서 따로 확인해 주세요.
끄려면 이 창에서 Ctrl+C 를 누르세요.
```

이 문구는 로컬 서버가 응답했다는 신호입니다. 기존 접근 제어/XDR 시스템이나 AI 게이트웨이에 연결됐다는 신호는 아닙니다. 기본 실행에서는 기존 시스템이 연결되지 않은 상태가 정상이며, 브라우저의 상단 상태와 `보호 현황`, `업무 앱`, `보안 기록` 메뉴를 확인합니다. 기본 실행 상태를 실제 연결 성공으로 기록하지 마세요.

### 실행 대안

`on-client` 폴더에서 다음 npm 스크립트를 사용할 수 있습니다.

| 명령 | 용도·범위 |
|---|---|
| `npm start` | `node src/server.mjs`를 실행합니다. 기본 포트는 서버 코드에서 5189입니다. |
| `npm run demo` | 예제 자료로 화면을 실행합니다. 실제 사용자·회사 시스템 연결이 아닙니다. |
| `npm run check` | `student/extension.mjs`의 Node 문법만 확인합니다. 화면·기능·네트워크 연결 검사는 아닙니다. |

처음에는 폴더·Node 버전·포트를 사전 점검하는 `start-alekov.ps1`을 권합니다. `npm start`는 그 PowerShell 실행 도구의 사전 점검을 거치지 않습니다.

## 4. 종료와 재실행

1. 앱을 시작한 PowerShell 창에서 `Ctrl+C`를 누릅니다.
2. 같은 창에서 프로세스가 끝난 것을 확인합니다. 브라우저 탭은 닫거나 그대로 둘 수 있습니다.
3. 다시 켤 때는 **같은 `on-client` 폴더**에서 3장의 실행 명령을 다시 실행합니다.
4. 다시 출력된 주소를 브라우저에서 엽니다. 다른 포트를 선택했다면 주소에도 그 포트를 사용합니다.

`start-alekov.ps1 -Background` 옵션은 서버를 뒤에서 실행하는 모드입니다. 이때는 실행 도구가 출력한 프로세스 번호의 `node` 프로세스를 작업 관리자에서 종료합니다. 초보자에게는 종료가 명확한 기본 전경 실행을 권합니다.

## 5. 글로 표현한 구성도

아래 화살표는 코드에 구현된 경로의 개요입니다. 외부 서비스 연결은 운영자가 별도로 발급·설정한 경우에만 가능하며, 이 안내서 작성 중 실제 연결을 확인하지 않았습니다.

```text
[브라우저]
    │ HTTP: http://127.0.0.1:5189/ (기본; 로컬 PC 전용)
    ▼
[로컬 Node.js 앱 서버: src/server.mjs]
    ├── 화면 파일 제공: public/index.html, public/app.js, public/style.css
    ├── 접근 판정·사용자/기기/세션·접속/XDR 기록 API
    │       └── 기본 실행: 연결 없음
    │           설정된 경우: student/engine-adapter.mjs
    │             → 서버가 전달한 호스트 기능 → 운영자가 별도 설정한 SDP 접근 제어/XDR 시스템
    └── 서버 측 AI 점검·사건 설명
            └── 앱 전용 권한·자격·모델 설정이 준비된 경우에만
                → 서버의 CLCO HTTP 클라이언트 → AI 게이트웨이

브라우저는 SDP/XDR 시스템이나 AI 게이트웨이에 직접 연결하지 않습니다.
AI 비밀값과 SDP 개인 자격은 브라우저 화면으로 전달하지 않는 서버 측 경계입니다.
```

코드에서 확인한 공개 주소와 연결 한계:

- 브라우저가 접속하는 로컬 주소는 `http://127.0.0.1:5189/`입니다. 포트 5189는 실행 도구의 기본값입니다.
- `src/ai/connection.mjs`에는 앱 연결 흐름용 공개 origin `https://ai-classroom-gateway-production.up.railway.app`와 승인 포털 `https://aleph-omega.vercel.app`이 선언되어 있습니다. 이는 코드에 적힌 주소이며, 이번 작업에서 접속 가능 여부나 연결 성공을 확인하지 않았습니다.
- 모델 요청 서버 주소는 `src/ai/service.mjs`가 `ON_AI_BASE_URL` 설정을 사용합니다. 저장소의 일반 실행 스크립트만으로 실제 설정값이나 사용 가능한 모델을 확인할 수 없으므로 여기에는 값을 적지 않습니다.
- 접근 제어/XDR의 실제 SDP 호스트는 운영자가 별도로 전달하는 설정에 의해 정해집니다. 실제 호스트 주소, 인증서·키·토큰 또는 설정 파일 내용은 이 프로젝트 안내서에 싣지 않습니다.

## 6. 구현·제공 코드 경계 및 기능 확인표

이 표의 “코드에서 확인”은 파일 내용을 읽어 구현 위치와 흐름을 확인했다는 뜻입니다. **이번 안내서 작업에서는 앱 테스트, 브라우저 확인, 외부 시스템 연결을 실행하지 않았습니다.** 기존 문서에 기재된 시험 기록은 해당 문서의 기록일 뿐, 이번에 재실행해 확인한 결과가 아닙니다.

| 기능·함수/경계 | 실제 코드 위치 | 코드에서 확인한 동작 | 이번 작업에서 실행 확인 |
|---|---|---|---|
| 학생 화면 표시 `createStudentView()` 및 `renderIdentity`, `renderDecision`, `renderEvents`, 상태·AI·취약점·조치 표시 함수 | `student/extension.mjs`; 화면 슬롯은 `public/index.html` | 학생 표시 영역과 공통 제공 UI가 나뉩니다. 연결 없음·예제·확인 불가와 실제 결과를 구분하도록 작성되어 있습니다. | 아니요. 화면 렌더링/학생 단계 통과 미확인 |

| SDP 호스트 경계와 어댑터 | `src/engine/sdp-host-config.mjs`, `src/engine/sdp-host.mjs`, `student/engine-adapter.mjs` | 명시된 외부 설정이 있을 때만 SDP 연결을 구성하도록 한 코드입니다. 계약 문서는 기록·기기·세션 조회 미지원은 가짜 빈 성공 대신 오류로 처리한다고 명시합니다. | 아니요. 개인 설정·실제 SDP/XDR 연결 미확인 |
| 패키지/취약점 조회 `createProjectScanner()` | `src/vulnerabilities/project-scan.mjs`, `src/vulnerabilities/osv.mjs` | 프로젝트 패키지 메타데이터를 읽고 승인 범위의 정확한 패키지/버전을 OSV 조회에 전달하는 코드입니다. 조회 불가 상태를 “취약점 없음”으로 바꾸지 않습니다. | 아니요. 실제 프로젝트 스캔·OSV 응답 미확인 |
| 실행 도구 | `tools/start-alekov.ps1` | Node 버전 범위, 앱 파일, 포트, 서버 HTTP 응답을 확인한 뒤 로컬 서버를 실행하는 스크립트입니다. HTTP 응답 확인은 AI 연결 검증이 아닙니다. | 아니요. PowerShell 실행 미확인 |

학생 담당 파일은 수업 단계 안내가 지정한 `student/extension.mjs`입니다. 기본 화면, 서버, 공통 제공 기능은 `public/`와 `src/` 아래 코드가 담당합니다. `student/engine-adapter.mjs`는 호스트 기능 연결 경계이며, 운영자 설정 없이 실제 시스템에 연결되는 것으로 간주하지 않습니다. 제공 파일을 임의로 고치지 말고 기존 학생 지침을 따릅니다.

## 7. 오류별 확인 순서

| 증상/메시지 | 확인 순서 | 재실행·도움 요청 |
|---|---|---|
